Привет из контейнера! 🐳

Статический сайт на Nginx. Dockerfile собирает HTML и CSS в образ, а bind mount позволяет менять страницу во время работы контейнера.

HTML обновлён без пересборки образа и перезапуска контейнера

Как браузер получает страницу

  1. Файлы сайтаindex.html + style.css
  2. Контейнерnginx:alpine · :80
  3. Браузер127.0.0.1:8087

Из чего состоит проект

Docker

Собирает файлы приложения и среду запуска в образ. Из одного образа можно запустить несколько отдельных контейнеров.

Nginx

Принимает HTTP-запросы на порту 80 и отдаёт файлы из /usr/share/nginx/html.

Dockerfile

Описывает сборку. Здесь он выбирает базовый образ Nginx, копирует два файла сайта и объявляет порт 80.

Сборка и запуск

Выполните команды PowerShell в каталоге с Dockerfile.

docker build -t profile-test-nginx-lab14 .
docker run -d --name profile-test-nginx-lab14-built -p 127.0.0.1:8087:80 profile-test-nginx-lab14
